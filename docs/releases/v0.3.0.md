## 新增行为

故障智巡从指定 Fixture 案例调查扩展到认证告警入口：阈值告警送入 Webhook，经 SQLite 幂等投递和服务/环境/指纹/窗口聚合形成 Incident；持久化 Worker 领取后实际只读采集演示服务日志/指标、检索通用 Runbook，保存 Evidence、知识引用、真实工具事件、诊断或人工升级，并在原 Console 中展示和回放。

- Alertmanager v4 协议 DTO 兼容，未知 severity 保留原值与标记，不静默降低风险；P0–P3 优先级独立于动作 SAFE/ASK/BLOCK。
- 现场 LIVE ID 与严格 INC-xxx Fixture 路由分离；数据源/凭据由宿主绑定，有窗口、条数、字节、超时、取消与范围限制。
- Runbook 标题/段落切片与 BM25，引用携带章节/文档版本/内容哈希/位置/原文片段；知识不当观测证据。
- 原子任务领取、租约 fencing、有限重试和持久化预算；不足/冲突/不可用/无效输出/预算耗尽如实收敛人工处理，不发送外部通知。
- Console 新告警与任务、事实/假设/不足、观测/手册引用、真实事件/只读 Replay；旧案例、审批、历史保留。
- 人工受控恢复后重新取证，分别保存人工声明、恢复效果与故障最终调查状态；verified 不自动 RESOLVED。

## 复现

按[迁移说明](../v0.3.0-migration.md)准备原依赖、Python 3.13 和已安装 Chromium，在仓库根执行：

```powershell
npm run build:all
node node_modules/tsx/dist/cli.mjs scripts/accept-v030-step7.ts --legacy-ui
# 可选，已有启用 Provider；不保证诊断成功，预算有限
node node_modules/tsx/dist/cli.mjs scripts/accept-v030-step7.ts --configured-model --legacy-ui
```

命令仅管理自己创建的随机 loopback 服务/测试库/浏览器/私有工作目录，结束清理；非敏感演示摘要/截图在仓库外 output。不要把 personal data、API key、运行库、原始日志或整个 output 作为 Release 附件。
